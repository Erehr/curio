# Scopes

The **Library** sidebar switches between built-in views, pinned shortcuts, folders, smart folders, indexed locations and the Tag Manager.

## Built-in views {#quick-views}

Built-in views sit at the top of the **Library** sidebar with live asset counts:

| View | What it shows |
|---|---|
| **All** | Every non-trashed asset in the library, including managed files and indexed locations. |
| **Favorites** | Every non-trashed asset marked with **Favorite** from the Inspector, **Rating › Favorite**, `item.update` or the **Toggle favorite** shortcut. |
| **Uncategorized** | Assets that do not belong to any library folder. Assets indexed in place inside Locations are excluded. |
| **Untagged** | Assets that have no tags attached. |

## Recent & Random

- **Recently used**: Shows assets you recently opened, imported or edited, newest first.
- **Random**: Displays your library in a shuffled order. Click **Shuffle again** or re-select **Random** for a new order without changing sort settings in other views.

## Missing & Trash

- **Missing & offline**: Collects assets whose files are unreachable. It separates **Storage offline** (an unplugged drive or disconnected share) from **Missing** (the drive is online, but the file moved or disappeared outside Curio). See [Recover files and library data](../help/storage.md).
- **Trash**: Lists trashed assets and folder entries so you can **Restore** them or run **Empty trash** permanently. See [File operations and trash](../organize/file-actions.md).

## Trees & tags

- **Folders**: Click a folder to view its assets. Toggle **Show subfolders** and **Show subfolder contents** independently in the **Layout** popover to show subfolder cards above the grid or include nested assets.
- **Locations**: Expand an indexed Location in the sidebar to browse its directory tree on disk. Clicking a location root or subdirectory supports the same **Show subfolders** and **Show subfolder contents** controls and full breadcrumbs as folders.
- **Smart Folders**: Click a smart folder to evaluate its live query. Smart folders with **Automatic subfolders** expand in the sidebar into dynamic virtual subfolders by date, rating, type, extension, tag or custom field. See [Build smart folders](../search/smart-folders.md).
- **Pinned**: Drag or pin frequent folders, smart folders, tags and location directories into **Pinned** at the top of the sidebar. Drag entries inside **Pinned** to reorder them.
- **All tags**: Opens the full-screen **Tag Manager**. Click any individual tag in the sidebar to filter to assets carrying that tag.

## History

- **History navigation**: Use the toolbar **Back** (++alt+left++) and **Forward** (++alt+right++) buttons, or your mouse side buttons. Configure side buttons in **Settings › Controls › Mouse side buttons** as *Back / forward*, *Previous / next item* or *Nothing*. When the viewer is open, **Back** returns to the grid before stepping through earlier views.
- **Breadcrumbs**: The toolbar breadcrumb shows the path to the active folder, smart folder or location directory. Click any parent segment to jump to that level.

## Selection

Multi-selection works across Grid, Masonry, Justified, List and Spectrum views:

| Action | Gesture or shortcut |
|---|---|
| Select one asset or subfolder card | Single click |
| Open asset or subfolder | Double-click or ++enter++ |
| Select a contiguous range | ++shift+click++ or ++shift+arrow-keys++ |
| Toggle individual assets in selection | ++ctrl+click++ |
| Select all assets in the current view | ++ctrl+a++ |
| Select an entire display group | Right-click a **Group by** header › **Select items in group** |
| Clear selection | Click empty space or press ++escape++ |
| Drag marquee selection | Drag on empty grid background to lasso assets |
